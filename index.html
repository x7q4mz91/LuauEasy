The basics

Luau reads your script from top to bottom. Use print() to show a value in the output.

Values

Text goes inside quotes. Numbers can be calculated. A boolean is either true or false.

Variables

Use local to give a value a name. You can use that name later in the script.

Comments

Start a comment with --. Luau skips it when your script runs.
